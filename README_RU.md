# Кусочки — Android-проект

Этот репозиторий содержит Android-оболочку для HTML-игры «Кусочки».

## Сборка APK
После добавления игры в `app/src/main/assets/index.html`:
1. Откройте вкладку **Actions**.
2. Выберите **Build Android APK** и нажмите **Run workflow**, либо отправьте новый commit в `main`.
3. Откройте завершившийся запуск и скачайте artifact `Kusochki-debug-APK`.
4. В ZIP-архиве будет `app-debug.apk`. Скачайте его на Android и откройте для установки. Android может попросить разрешить установку приложений из этого источника.

Это debug-сборка для личной установки, не релизная версия для Google Play.
