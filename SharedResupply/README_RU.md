# Shared Resupply — клиентская установка для HELLDIVERS (2015)

Это клиентский мод для Obsidian Mod Loader / Obsidian Mod Manager. Он запускается на клиентах игры; это не серверный плагин и не отдельная игра.

## Установка

1. Установите Obsidian Mod Loader / Obsidian Mod Manager.
2. Убедитесь, что установлен Obsidian API версии 1.40.0 или новее.
3. Скопируйте папку `SharedResupply` целиком в каталог модов Obsidian.
4. Включите Shared Resupply в менеджере модов.
5. Для совместной игры мод должен быть установлен у каждого участника лобби, причём версия и настройка Preserve vanilla Resupply должны совпадать.

## Поведение

- Каждый игрок получает жёлтый Resupply в миссии.
- Один вызов сбрасывает ящик с четырьмя коробками боеприпасов.
- Время вызова — 10 секунд.
- Перезарядка — 180 секунд, общая для отряда.
- По умолчанию стандартный Resupply скрывается.
- Опция Preserve vanilla Resupply сохраняет стандартный Resupply и переносит его комбинацию на свободную последовательность.

## Структура

- `obsidian.json`, `main.lua`, `image.png` — манифест, точка входа и изображение.
- `src/` — четыре Lua-модуля.
- `res/` — текстура и материал значка.

## Важное ограничение

Мод работает на клиентской стороне через Obsidian, но функция общей перезарядки требует одинаковой установки у всех игроков. Удаление `every_player` или отключение session scope не является безопасным способом сделать его «только у хоста» или «только у одного клиента»: это меняет сетевое поведение мода.
