# Shared Resupply — экспериментальная client-scope версия

Это отдельная экспериментальная адаптация Shared Resupply 1.1.0 для HELLDIVERS (2015) и Obsidian Mod Loader.

## Чем отличается от оригинала

- В манифесте установлен `"scope": "client"`.
- Удалён параметр `every_player`: мод не требует, чтобы каждый участник лобби установил его.
- Стратагема добавляется локально на стороне игрока, у которого включён этот мод.
- Общая перезарядка отряда отключена. Используется обычная индивидуальная перезарядка базовой стратагемы Resupply.
- Локально скрывается стандартный Resupply либо, при включённой опции Preserve vanilla Resupply, его комбинация переносится на свободную последовательность.
- Хук ящика оставляет четыре коробки боеприпасов для ящика, вызванного этой стратагемой.

## Установка

1. Установите Obsidian Mod Manager / Loader.
2. Убедитесь, что Obsidian API версии 1.40.0 или новее включён.
3. Импортируйте папку `SharedResupply` через вкладку Mods.
4. Включите **Shared Resupply (Client)** и запустите игру через Obsidian.

## Важные ограничения

Это экспериментальная сборка. Она не синхронизирует стратагему и её перезарядку между участниками: каждый игрок управляет только своей локальной копией. Игроки без мода не получат эту стратагему в своём наборе.

Содержимое ящика должно появляться как игровые предметы, создаваемые клиентом игрока, который вызвал стратагему. Но видимость и корректная репликация четырёх коробок для остальных участников ещё требуют проверки в реальной игре.

## Проверка

- Манифест и Lua-логику адаптировано под client scope.
- Общий вызов `share_cooldown` и его отмена удалены.
- Файлы ресурсов и исходная логика создания четырёх коробок сохранены.
- Запуск в игре, одиночный тест и сетевой тест ещё не выполнялись.

Если клиентский режим Obsidian запрещает один из используемых API-вызовов или хук, это будет видно по журналу Obsidian; тогда потребуется дополнительная адаптация.
